# Groundbreak

A realistic first-person house-building game: pour the concrete, frame it, rough-in plumbing and electrical, hang drywall, roof, side and landscape — with real tools on a tool belt and materials ordered from an in-game tablet. Everything snaps to a small grid and 45° angles (G / R to change).

## Play
1. Install Unity **6000.6.8f1** via Unity Hub.
2. Unity Hub → Add project from disk → this folder.
3. Open any empty scene and press **Play**. Press **T** for the tablet (Help lists all controls).

## Status
Milestone 1 (snap grid, tool belt, framing tools, tablet store, deliveries, realistic materials and products) is in. See `CLAUDE.md` for conventions and the roadmap in the spec.
